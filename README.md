# Personal Portfolio Website

A responsive personal portfolio that showcases my profile, technical skills, projects and web development journey, and gives visitors a way to contact me.

## Features
- Personal introduction with typing animation
- About, Skills (animated bars), Projects (filterable cards), Journey timeline
- Responsive layout with mobile menu
- Dark / light theme (remembered between visits)
- Contact form with validation (opens the visitor's email app)
- Scroll animations, active-link highlighting, back-to-top button

## Run
Open `index.html` in any browser. No build step or dependencies.

## Customize
- Replace `youremail@example.com` in `index.html` and `script.js`
- Update LinkedIn link, skills and projects in `index.html`

## Deploy (GitHub Pages)
Push to GitHub, then Settings → Pages → deploy from the `main` branch.

## Tech
HTML5, CSS3 (grid, flexbox, variables), vanilla JavaScript.

## Purpose
To build a professional digital identity and present my skills and projects to recruiters, developers and potential collaborators.
